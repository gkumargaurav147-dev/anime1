# Asset licences

Only three kinds of art may ship: **made by us**, **work-for-hire owned by us**, or **CC0**.
Every asset file in the repo needs a row here before it is merged.

| Asset                                                                                  | Files                                                                       | Author / source                                            | Licence                                     | Added      |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------- | ---------------------------------------------------------- | ------------------------------------------- | ---------- |
| Placeholder 2.5D avatar art (heads, faces, hair, outfits, accessories, hands, effects) | generated at runtime by `packages/scene-engine/src/avatar/levelA/bust.ts`   | Written for this project (procedural code, no image files) | Owned by us                                 | 2026-11-21 |
| Placeholder 3D bust (procedural geometry + morph targets)                              | generated at runtime by `apps/mobile/src/avatar/levelB/proceduralBust.ts`   | Written for this project (procedural code, no model files) | Owned by us                                 | 2026-11-21 |
| Scene placeholder art (backgrounds, props, effects, speech bubble)                     | generated by `packages/scene-engine/src/assets/PlaceholderAssetProvider.ts` | Written for this project                                   | Owned by us                                 | 2026-11-21 |
| Expression and gesture data                                                            | `packages/scene-engine/src/avatar/expressions.v1.json`, `gestures.v1.json`  | Written for this project                                   | Owned by us                                 | 2026-11-21 |
| App icons / splash                                                                     | `apps/mobile/assets/*.png`                                                  | Expo `blank-typescript` template                           | MIT (Expo template) — replace before launch | 2026-11-21 |

Prop and effect glyphs in the placeholder scene art use the device's **system emoji font** at
render time; no emoji image files are bundled.

Third-party code libraries (three.js, react-three-fiber, expo-gl, …) are dependencies, not art;
their licences are in `node_modules/<pkg>/LICENSE` (all MIT/Apache-2.0).

Blendshape _names_ follow a widely used naming convention for facial morph targets; the names
are descriptive identifiers only and no third-party data or assets are included.
